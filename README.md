# Airtel vs MTN Network Comparison

A data analysis project comparing user experience between Airtel and MTN, Nigeria's two leading telecom networks.

## Overview
Collected survey responses from Airtel and MTN users and analyzed the data in Excel, SQL and Power BI to uncover trends in network performance, service quality, pricing and overall user satisfaction.

## Tools
- **Excel** — data cleaning and initial trend analysis
- **SQL** — querying and structuring the survey data
- **Power BI** — interactive dashboard for visualizing insights

## Key Insight
No single network came out on top. Each provider showed distinct strengths depending on the metric, revealing that "best network" depends on what a user values most (coverage, pricing, speed or reliability).

## Files
- `PowerBi Project.pbix` — interactive dashboard
- `Python Project.ipynb` — data analysis in Python (pandas)
